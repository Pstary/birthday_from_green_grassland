# 青青草原 · 生日派对

一个生日祝福收集站。朋友可以录制语音、寄出祝福信和上传照片。每位朋友只看到当前浏览器提交的内容，寿星登录后可以查看全部投稿。

## 本地启动

安装 Node.js 24 或更高版本。项目使用 Node.js 自带的 HTTP 和 SQLite 模块，无需安装额外依赖。

1. 下载或克隆仓库，进入包含 `server.mjs` 的目录。
2. 在项目根目录创建 `owner-password.txt`，写入一行自己设置的寿星口令。也可以通过环境变量 `BIRTHDAY_OWNER_PASSWORD` 配置口令。
3. 运行：

   ```bash
   npm start
   ```

   也可以直接运行 `node server.mjs`。
4. 在浏览器打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。打开身份菜单，输入口令即可切换为寿星。

首次启动时会自动创建 `birthday.sqlite`。录音需要浏览器的麦克风权限。本机可以使用 localhost，跨设备访问需要部署到朋友可访问的 HTTPS 地址。

## 本地数据

- `birthday.sqlite` 保存投稿和媒体。迁移或备份时先停止服务，再复制数据库及同名的 SQLite 辅助文件。
- 朋友身份由当前浏览器的 Cookie 识别。换浏览器或清除 Cookie 后会获得新的朋友身份。
- 寿星口令、数据库和备份都属于本地数据。请不要上传到 GitHub。
- GitHub 仓库存放项目源码。语音、祝福和照片的提交需要运行 Node.js 服务。
